CAS GENE DETECTION WORKFLOW - REQUIREMENTS
============================================

FUNCTIONAL REQUIREMENTS
-----------------------

FR1: ORF Detection
- System shall find ALL Open Reading Frames (ORFs) in SDBG at specified distances
- Start codons: ATG, GTG, TTG
- Stop codons: TAA, TAG, TGA
- First gene: search distance 50-5000bp from repeat node
- Subsequent genes: search 0-100bp from tail nodes of previous gene
- Min ORF length: 108bp (shortest HMM profile)
- Max candidates: 5000 per search

FR2: HMM Profile Selection
- System shall filter HMM profiles based on ORF length (bp)
- Filter criterion: min_bp < orf_length < max_bp
- Profile database: 705 HMM profiles from HMMER3

FR3: Sequence Scoring
- System shall score ALL candidate ORFs with ALL matching profiles
- Amino acid translation: DNA triplets → 20 amino acids
- Scoring: HMM log-odds via Viterbi beam search
- Selection: BEST ORF+profile combination by score

FR4: Iterative Detection
- System shall detect multiple CAS genes iteratively
- First ORF: find ALL ORFs in 100-500bp range, score all, select best
- Subsequent ORFs: search from last ~15 nodes of previous gene path
  * Handles 1-4bp overlaps (start codon in tail region of previous gene)
  * Searches 0-100bp forward from each tail node
  * Collects all unique ORFs, scores all, selects best
- Stop condition: total length ≥ 41,591bp OR no more ORFs

FR5: Output
- System shall return detected genes with:
  * Gene name (from best HMM profile)
  * Genomic coordinates (start/end nodes)
  * Score and amino acid sequence
  * Distance from repeat node

PARAMETERS
----------
- Initial search distance: 50-5000 bp from repeat (default)
- Subsequent search distance: 0-100 bp from tail nodes (default)
  * Searches from last ~15 nodes of previous gene to find overlaps
  * Allows detection of 1-4bp overlapping genes (common in prokaryotes)
- Max total operon length: 41,591 bp (default)
- Max candidates per search: 5000
- Beam width: 10 (default)
- Max search depth: 500 nodes (default)
- Min ORF length: 108 bp (shortest HMM profile)

DEPENDENCIES
------------
- SDBG library (megahit)
- HMM profiles (HMMER3 format)
- ORFFinder module
- CasGeneDetector module
- Profile loader
- HMMPicker (buckets.h)

CONSTRAINTS
-----------
- Memory: ORF length capped at 5000bp
- Performance: Beam search limits candidates to beam_width
- Data: Requires pre-built SDBG and HMM profile directory
- Traversal: Limited to 5000 nodes per search

BIOLOGICAL CONSTRAINTS
----------------------
- Overlapping genes: 1-4 bp overlap (e.g., ATGA where TAA stop overlaps ATG start)
- Intergenic spacing: 0-100 bp gaps between genes (typically < 20bp)
- Operon organization: Co-transcribed genes in tight clusters
- Overlap detection: Searches from last ~15 tail nodes of previous gene

LIMITATIONS & CAVEATS
---------------------
- Distance tracking is approximate: node path position ≈ sequence position
  * Each node in path assumed ~1bp increment (nodes overlap by k-1)
  * Actual distances may be off by a few bp depending on graph structure
- Tail node search: uses last 15 nodes to ensure overlap coverage
  * Trade-off between finding overlaps and computational efficiency
- Score-based selection: relies on HMM profile quality and alignment accuracy
