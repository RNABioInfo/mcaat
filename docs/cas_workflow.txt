CAS GENE DETECTION WORKFLOW v2

================================================================================
CONTEXT
================================================================================

We have a de Bruijn graph (SDBG) and a repeat node R from CRISPR array detection.
Cas genes are located in the direction of OutgoingEdges from R.
We use HMM profiles to guide the search and scoring.

================================================================================
DEFINITIONS
================================================================================

1. R: Repeat node from CRISPR detection

2. Traverse direction: sdbg.OutgoingEdges()

3. Start codon: ATG, GTG, TTG

4. Stop codon: TAA, TAG, TGA

5. ProfileSize: HMM profile metadata containing filename, leng, min_aa, max_aa, min_bp, max_bp

6. Normalized score: bit_score / hmm_positions_used, where hmm_positions_used = hmm_end_pos from ViterbiAlign

================================================================================
PARAMETERS
================================================================================

1. FIRST_GENE_MIN_DIST = 50
   Minimum distance from R to first gene start

2. FIRST_GENE_MAX_DIST = 1000
   Maximum distance from R to first gene start

3. MAX_START_CANDIDATES = 5000
   Cap on start codon nodes to evaluate

4. MAX_LOCUS_BP = 41591
   Stop when cumulative distance from R exceeds this

5. OVERLAP_ALLOWANCE = 15
   Bp before previous gene end to allow overlap

6. INTERGENIC_MAX = 100
   Max bp gap between genes

7. BEAM_WIDTH = 10
   Beam search width

8. MIN_NORMALIZED_SCORE = 0.0
   Minimum normalized bit score to accept a gene

================================================================================
ALGORITHM
================================================================================

STEP 0: Find first gene start codon candidates
--------------------------------------------------------------------------------

1. BFS from R using OutgoingEdges

2. Collect all nodes containing start codons in range [FIRST_GENE_MIN_DIST, FIRST_GENE_MAX_DIST]

3. Cap at MAX_START_CANDIDATES

4. Output: list of (start_node, distance_from_R)


STEP 1: Score each start with all HMM profiles
--------------------------------------------------------------------------------

1. For each start_node:

    1.1. For each ProfileSize P in ALL_PROFILES:

        1.1.1. max_depth = P.max_bp

        1.1.2. Run BeamSearchAminoAcids(start_node, BEAM_WIDTH, max_depth)

        1.1.3. BeamSearch traverses graph at each step:
               (a) Extend path by one node (one nucleotide)
               (b) Translate accumulated sequence to amino acids
               (c) Run ViterbiAlign on amino acids to get bit_score
               (d) Use bit_score as path weight for beam pruning
               (e) Keep top BEAM_WIDTH paths by bit_score

        1.1.4. BeamSearch stops when:
               (a) stop codon hit
               (b) max_depth reached
               (c) HMM fully aligned

        1.1.5. Get final bit_score and hmm_end_pos from best path

        1.1.6. Calculate normalized_score = bit_score / hmm_end_pos

        1.1.7. Record:
               - start_node
               - profile_name
               - normalized_score
               - bit_score
               - end_node
               - path_length
               - amino_acids
               - node_path

    1.2. Keep best scoring profile for this start_node (by normalized_score)


STEP 2: Select best gene
--------------------------------------------------------------------------------

1. From all (start_node, best_profile) pairs, select the one with highest normalized_score

2. Reject if normalized_score < MIN_NORMALIZED_SCORE

3. Record gene with:
   - start_node
   - end_node
   - profile_name
   - normalized_score
   - bit_score
   - gene_length
   - distance_from_repeat
   - amino_acids
   - node_path

4. Update cumulative_length = distance_from_repeat + gene_length


STEP 3: Find subsequent genes (loop)
--------------------------------------------------------------------------------

1. While cumulative_length < MAX_LOCUS_BP:

    1.1. previous_gene_end = previous_gene.distance_from_repeat + previous_gene.gene_length

    1.2. search_start = previous_gene_end - OVERLAP_ALLOWANCE

    1.3. search_end = previous_gene_end + INTERGENIC_MAX

    1.4. BFS from R, collect all start codon nodes in range [search_start, search_end]

    1.5. Cap at MAX_START_CANDIDATES

    1.6. For each start_node, score with all HMM profiles (same as Step 1)

    1.7. Select best gene (same as Step 2)

    1.8. If no gene found with normalized_score >= MIN_NORMALIZED_SCORE, stop

    1.9. Update cumulative_length = new_gene.distance_from_repeat + new_gene.gene_length

================================================================================
SCORING DETAILS
================================================================================

1. ViterbiAlign returns: (bit_score, alignment_path, hmm_end_pos)

2. hmm_end_pos = number of HMM match/delete states traversed

3. normalized_score = bit_score / hmm_end_pos

4. This normalization handles insertions properly since insertions do not increase hmm_end_pos

5. Allows fair comparison between short profiles (43 states) and long profiles (1000+ states)

================================================================================
OUTPUT
================================================================================

List of DetectedCasGene, each containing:

1. profile_name
2. start_node
3. end_node
4. distance_from_repeat
5. gene_length
6. normalized_score
7. bit_score
8. amino_acids
9. node_path
