---CAS SUBROUTINE---
0. Find ALL possible ORFs in DISTANCE from 100-500bp from node R
   (for first gene). Max nodes to traverse: 5000.
   Only consider ORFs with length >= 108bp (shortest HMM profile).
   
1. For EACH possible ORF in the collection:
    - Select matching HMM profiles based on ORF length. Module: buckets.
    - For EACH profile_name in collected_profile_names:
        - Pick START node_id from ORF
        - Load HMMProfile with name = profile_name
        - Run Viterbi beam search with current_HMM_profile
        - Record maximum scored path from BeamSearch
    - Best performing/scoring profile wins for this ORF
    
2. Pick the BEST ORF+profile combination across ALL candidates
   based on the highest score.

3. For subsequent genes:
   - Search from last ~15 nodes of previous gene's path (tail nodes)
   - This handles 1-4bp overlaps where start codon appears in tail region
   - Search distance: 0-100bp from each tail node
   - Max nodes to traverse: 500
   - Collect all unique ORFs from all tail node searches
   - Score all ORFs with all matching profiles
   - Select BEST ORF+profile combination

WE STOP THE CAS SUBROUTINE WHEN TOTAL LENGTH BETWEEN
REPEAT R NODE AND THE END OF THE LAST DETECTED ORF 
REACHES 41591

** Overlapping genes: Many cas genes overlap by 1–4 bp (e.g., ATGA where the stop codon of one gene overlaps the start codon of the next), which is common in prokaryotic operons under translational coupling.
Short intergenic regions: When not overlapping, gaps are typically 0–100 bp, with most falling under 20 bp. This tight spacing reflects their organization in co-transcribed operons.

CONS/LIMITATIONS:
- Distance tracking is approximate (each node ≈ 1bp)
- Searches last 15 tail nodes (trade-off: coverage vs efficiency)
- Relies on HMM profile quality for accurate gene detection
