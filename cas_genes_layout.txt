CRISPR-Cas Classification Reference (Complete)


NAMING CONVENTION: Unified Cas# system
Old subtype-specific names shown in (parentheses) for reference.



                              SYSTEM OVERVIEW


CRISPR-Cas systems consist of:

1. CORE GENES — Essential for CRISPR function
    Adaptation module: Cas1, Cas2, (Cas4) — acquire new spacers
    Processing module: Cas6 — mature crRNA
    Interference module: effector complex — destroy targets

2. ACCESSORY GENES — Enhance defense, signaling, regulation
    Signaling amplification (nucleases, membrane proteins)
    Transcriptional regulation (HTH, WYL)
    Alternative acquisition (RT)
    Abortive infection (Abi)



                          CLASS 1 — Multi-subunit

Multiple proteins assemble together to form the interference machinery.
